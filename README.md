# Anvos DevBox — official releases

Windows installer for the **devbox app** of [Anvos Studio](https://anvos.dev), the AI-native
software studio built on Claude.

A devbox is the machine where your coding agents and your code live. Install the app on your
Windows computer, sign in, and drive Claude Code sessions on it from
[studio.anvos.dev](https://studio.anvos.dev) — on your desktop or your phone.

> Anvos Studio is in **early access**. You need an Anvos Studio account to use the app —
> request access at **founder@anvos.dev**.

## Requirements

- Windows, 64-bit
- An Anvos Studio early-access account
- Your own Claude account

## Install

1. Run `anvos-devbox-win-x64.msi`.
2. The installer is not code-signed yet, so Windows SmartScreen may show
   *"Windows protected your PC"*. Choose **More info → Run anyway** only if you downloaded the
   file from this page.
3. Open **Anvos DevBox** from the system tray and sign in.
4. Your devbox appears in [Anvos Studio](https://studio.anvos.dev) — start a session from any device.

## Updates

The app updates itself. Every update is checked against a signed manifest before it is
installed, so only builds published by Anvos Studio are accepted.

## Uninstall

Windows **Settings → Apps → Installed apps → Anvos DevBox → Uninstall**.
